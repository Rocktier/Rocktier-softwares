# Rocktier Softwares

Rocktier 家族的全部桌面软件源码（monorepo）。

| 目录 | 产品 | 说明 |
| --- | --- | --- |
| apps/pdf | Rocktier PDF | PDF 阅读、批注、合并、压缩、签名、OCR |
| apps/markdown | Rocktier Markdown | Markdown 写作与即时预览 |
| apps/ocr | Rocktier OCR | 扫描件转可搜索文字 |
| apps/write | Rocktier Write | 长文写作工作台 |
| apps/pic2webp | Rocktier Pic2WebP | 图片批量转 WebP |
| apps/cad-viewer | Rocktier CAD Viewer | DWG/DXF 看图 |
| apps/compressor | Rocktier Compressor | PDF/Office/图片批量压缩 |
| apps/journal | Rocktier Journal | 加密日记 |

> 由 8 个独立仓库经 git subtree 合并而来，完整提交历史保留在各目录内。

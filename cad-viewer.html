Questions, answered.

Which file versions can I open?

DWG files from the current release back to older formats, and DXF in its common versions. If a file won't open, tell us: compatibility is our top priority.

Can I edit drawings?

No. This is a viewer on purpose. It reads the drawing, measures it, and inspects it, and never risks corrupting the original.

Do my drawings leave my device?

Never. Viewing happens entirely locally: no upload, no cloud component.

Is it a subscription?

No. One-time purchase, updates included, nothing to renew.

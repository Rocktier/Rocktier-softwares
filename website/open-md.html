How to open a .md file

A .md file is just plain text, so any text editor can show you the raw characters. To see headings, tables, code blocks and images as a page, open it with a Markdown app. Here are the ways that work on both Windows and macOS.

What is inside a .md file?

Markdown uses plain punctuation for structure: a # for a heading, dashes for a list, backticks for code. The file stays readable forever, because it is text. A Markdown app renders those marks into a formatted page and, if you want, lets you edit the text beside it.

On macOS

  • Install the app once, then double-click any .md file in Finder. If another app is set as the default, right-click the file, choose Open With, and pick Rocktier Markdown.
  • You can also drag the file onto the app icon in the Dock, or onto an open window.
  • To make it stick, use Get Info, set Open With, then click Change All. macOS will remember it for that extension.

On Windows

  • Install the app once, then double-click the file in File Explorer. If it opens in Notepad, right-click, choose Open with, then Choose another app and pick Rocktier Markdown.
  • Tick "Always use this app to open .md files" in that dialog to make it the default.
  • Dragging the file onto an open window works too, and skips the default-app setting entirely.

Which extensions count as Markdown?

Rocktier Markdown registers eight common Markdown extensions. They are all plain text, so even a file with an unusual extension can be opened from inside the app with File, then Open.

.md · .markdown · .mdown · .mkd · .mkdn · .mdwn · .mdtxt · .mdtext

When it does not look right

  • You see the raw marks instead of a page: the file is open in a plain text editor. Change the default app as described above.
  • Images are missing: Markdown stores image paths, not the images. Keep the pictures next to the .md file, or use paths that still resolve from where the file lives.
  • Chinese text is garbled: the file was saved in a legacy encoding. Re-save it as UTF-8, which is what Markdown apps expect.

Do you need to upload it anywhere?

No. Opening, reading and exporting a .md file all happen on your device. Rocktier Markdown has no account and no cloud, and the file itself never leaves the folder you chose.

Questions, answered.

Where are my notes stored?

As plain .md files in folders you choose. There is no hidden database and no cloud sync. What you save is what you own.

What can I export to?

PDF, printed from the rendered preview, and a single .html file with styles and local images embedded so it opens in any browser. Remote images stay as links. The source file is never touched.

Is it a subscription?

No. One-time purchase, updates included, nothing to renew.

Does it need an internet connection?

Not for writing, reading or exporting: those work fully offline, on a plane, a train, or a cabin in the woods. You do need a connection to activate a license and to check for the latest version; the app never does either on its own. Every request is listed on our privacy page.

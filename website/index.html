Six promises, kept.

Offline by default

Every file is opened, changed and saved on your machine. No upload step, no queue, no server in the middle.

No account, no telemetry

Nothing to sign up for, nothing phoning home. The only outbound request is one you start yourself: a licence check, or a search for updates.

One payment

Between $4.99 and $14.99 for a single app, $29.99 for all eight. No subscription, no renewal, updates included.

Fast is a feature

No account screen and no dashboard to load first. The window appears with the file already open.

Files you can leave with

Markdown any editor opens, PDFs any reader opens, WebP any browser shows. Nothing is locked in a database only we can read.

A licence you keep

One code covers Windows and macOS, and you can move it to a new machine yourself when the old one dies.

Try it before you pay for it.

Direct downloads include a 7-day trial. One licence starts at $4.99, the whole family is $29.99, and both are yours to keep.

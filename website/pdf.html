Questions

Does it upload my file?

No. Everything happens on your machine: that is the point of the app. This page loads nothing but static files, and the editor never opens a network connection.

Is it a subscription?

No. $9.99 once. There is no account to create and nothing to renew.

How does the Markdown export handle tables?

Version 1 detects table-like regions and tells you where they are, but keeps their contents as plain text rather than guessing the column structure: a wrong table is worse than honest text.

Does it work on Intel Macs?

The macOS build is Apple Silicon. On an Intel Mac, use the Intel (x86_64) download on this page; it links to the latest x64 DMG from the release page.

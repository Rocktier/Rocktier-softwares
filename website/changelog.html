What changed. In plain words.

Our apps never phone home, so they cannot announce their own updates. The latest releases add a manual update check (Help → Check for updates): one request, only when you click. This page is where to look, and your app's About or Settings screen shows the version you are on.

Rocktier Write

2026-11-15 · v1.4.19

  • New: compare the open draft with the file on disk, line by line, without leaving the app.
  • Interface: a soft light background with a translucent title bar, chapter list, floating menus and dialogs, in both themes. Text stays on solid surfaces.
  • Fixed: in Rich mode the find bar could land at the bottom of the window. It now sits at the top.
  • Fixed: Ctrl+F opened a second, browser style find bar on Windows. It now opens the app's own.
  • Fixed: the chapter selection box is a quiet neutral box instead of a white strip with a coloured edge.
  • Fixed: the link dialog announces itself to screen readers, and the language icon now matches the theme icon in size.

2026-11-13 · v1.4.16

  • Fixed: the "file changed on disk" warning during draft recovery never appeared, because the app could not read file timestamps. It works now.

2026-11-05 · v1.4.15

  • Fixed: while a document had unsaved edits, the word "Unsaved" in the top bar could be painted on top of the New button and swallow your click on it. It now keeps its own space.
  • Fixed: the chapter list no longer draws over the document tabs where the sidebar meets the tab strip.
  • Interface: the ✕ that closes a tab is easier to hit. The mark stays small, but the area that responds to a click is now at least 24×24.
  • Interface: inserting a link uses the app's own dialog. A system prompt used to open behind the window, which made the link button look like it did nothing.
  • Interface: the find-and-replace bar's match counter and "match case" option now follow the app's styles instead of the browser's defaults, and the previous and next buttons announce themselves to screen readers.

2026-11-03 · v1.4.14

  • Housekeeping: a type error in the editor's test harness was fixed. No user-facing change is recorded for this release.

2026-10-25 · v1.4.11

  • Fixed: Rich mode stopped drawing a thick red frame around the whole page whenever the editor had focus.
  • Keyboard focus rings stay put on buttons, fields and menus, so shortcuts still show where you are.

Rocktier PDF

2026-11-15 · v1.2.2

  • Fixed: after a file opened successfully from Recent, the status bar could keep showing an error message left over from the previous attempt. It clears now.
  • Interface: dialogs take keyboard focus as soon as they open, so Escape and Tab work without clicking first.
  • Interface: the toast close button is now at least 24×24.

2026-11-15 · v1.2.1

  • Interface: the selected page thumbnail is marked with a quiet neutral box and an 8px corner, in place of the white card with a red edge.

2026-11-15 · v1.2.0

  • New: export selected pages as one long PNG image. The pages are stacked top to bottom in the order you pick, with a height cap that keeps the request from using all of your memory.
  • Interface: the eight task icons that were hard to tell apart now carry a small label under the icon, and the toolbar groups related tools so scanning is faster.
  • Interface: a new soft-light background with a translucent header, toolbar and status bar, in both light and dark themes. Text stays on solid surfaces, never on the glass.
  • Interface: the theme and language buttons are now the same size, and the language glyph was enlarged so it reads as clearly as the sun and moon icons.

2026-11-05 · v1.1.3

  • Fixed: opening a file from Recent gave no sign of life for several seconds, so it was easy to click it again. The row now shows that it is working, the other rows go dim until it finishes, and if an open is still running after 8 seconds the app releases the marker and shows the full path it was opening, in selectable text you can copy.
  • Interface: confirmations such as delete or clear now appear inside the app. A system prompt could open behind the window on Mac, which made the app look frozen.
  • Interface: "Clear recent files" is easier to click. Its clickable area is now at least 24×24. The text and colour are unchanged.
  • Interface: the status bar uses the same 28px height as the rest of the family, and menu items that need an open document are greyed out when there isn't one.

2026-10-29 · v1.1.1

2026-10-29 · v1.1.0

  • New: digital signing now lives inside PDF. Fill in a signature, place it on the page and verify signatures already in a document; certificates and licences from the old Sign app migrate automatically on first launch.
  • Rocktier Sign is no longer a separate download. See the note under Sign below.

2026-10-24 · v1.0.30

  • Interface depth reworked: cards, buttons and dialogs now sit at clearly separated levels.

Rocktier Journal

2026-11-15 · v0.2.17

  • Security: the answer to your password hint is now stored with a salted, deliberately slow hash. Existing vaults upgrade on the next unlock; nothing to do.
  • Fixed: the editor marked a note as saved before the write reached disk. It now waits for the write.
  • Interface: glass sidebar and dialogs over a softer background than the rest of the family. The selected entry is a quiet neutral box, and the trailing red dot is gone.

2026-10-24 · v0.2.16

  • New: recovery codes. If you forget your password you can now reset it with a recovery code, and your entries are not lost. Existing vaults migrate automatically the first time you unlock; nothing to do.
  • Fixed: the reset path had a flaw that made recovery impossible in practice. This release is the first where it actually works.
  • New: Intel Mac builds, so the app now runs on older Macs as well as Apple Silicon.
  • Interface depth reworked: cards, buttons and dialogs now sit at clearly separated levels.

Rocktier Compressor

2026-11-15 · v0.1.16

  • Interface: glass title bar, status bar, right panel and licence dialog over a soft light background, in both themes. Confirmations appear inside the app instead of a system prompt.

2026-11-03 · v0.1.15

2026-10-24 · v0.1.13

  • Fixed: compressing an Excel or Word file could produce nothing at all, because the engine was re-storing images in a way that made the output larger than the original, so it correctly backed out. It now compares every entry and keeps whichever is smaller, so the result is never bigger than what you started with.
  • New: PNG images inside documents are stored without their invisible transparency channel when nothing is actually transparent: identical pixels, roughly a third less data.
  • Fixed: no more temporary files left behind after a batch. A note now says the original is still on disk if you want to delete it.
  • Fixed: the quality-profile controls were pushed to one side; they now span the full width.
  • New: Intel Mac builds, so the app now runs on older Macs as well as Apple Silicon.
